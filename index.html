Sobre

Minha trajetória profissional não foi linear — e é justamente isso que define minha identidade como desenvolvedor. Com bagagem prévia e forte vivência humana e profissional, decidi direcionar minha paixão por lógica e resolução de problemas para a engenharia de software. Hoje, dedico-me a estudar Análise e Desenvolvimento de Sistemas e Engenharia de Software. No desenvolvimento diário, estruturo o backend com Java e Spring Boot, aplico persistência com JPA/Hibernate e PostgreSQL, e construo interfaces responsivas com TypeScript e Angular, utilizando boas práticas de versionamento com Git e conteinerização com Docker. Acredito que escrever código vai muito além de fazer a tela funcionar: envolve arquitetura limpa, boas práticas e a entrega de soluções reais que tragam valor para os usuários.

Projetos

Um dos projetos que venho desenvolvendo é uma aplicação para gerenciamento de uma clínica. O Sistema de Gestão para Clínica de Psicologia é uma aplicação web full-stack desenvolvida para otimizar o fluxo de agendamentos, pacientes e profissionais de uma clínica. Ele resolve o problema de centralizar e organizar o gerenciamento de consultas e cadastros, substituindo processos manuais por um fluxo digital integrado. O projeto foi construído utilizando Java, Spring Boot, Spring Data JPA, PostgreSQL, Supabase, Angular, TypeScript e Docker, com hospedagem no Render.
